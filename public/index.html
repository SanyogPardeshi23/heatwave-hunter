    What this is
    
        
    Heatwave Hunter is our Data Structures lab mini-project for the AI use case KJS-CES-01: Climate Intelligence for Heatwave Monitoring, Prediction and Early Warning. It reads real daily maximum-temperature data from IMD Pune and uses all eight lab experiments to find and track heatwaves across India from 2015 to 2025.
    
        
    Every operation — reading the data, the linked lists, stacks, queues, the BST, BFS on the graph, sorting, searching and hashing — is written in C with no standard library, and compiled to WebAssembly. The JavaScript on this page only draws what the C code returns.

    About the data
    
        
      
          
    • Source: India Meteorological Department, Pune — Yearly Gridded Maximum Temperature (1.0° × 1.0°), binary files, 2015–2025. A small C tool packs 1 March – 30 June for the 355 grid cells over India.
      • 
          
    • Each value is a 1° grid-cell average built from station reports, so peaks are lower than single-station records reported in the news.
      • 
          
    • IMD marks missing readings with 99.9. Those cell-days are skipped, never treated as temperatures.
      • 
          
    • From 2008 onward IMD builds these grids from around 180 stations, so 2015–2025 compare on equal terms.
      • 
          
    • Heatwave levels use IMD's actual-temperature rule for the plains (≥ 45 °C heatwave, ≥ 47 °C severe). IMD's departure-from-normal rule needs normal temperatures, which aren't in this dataset.
      • 
          
    • Citation: Srivastava, A. K., Rajeevan, M., Kshirsagar, S. R. (2009). Development of a high resolution daily gridded temperature data set (1969–2005) for the Indian region. Atmospheric Science Letters. DOI 10.1002/asl.232.
